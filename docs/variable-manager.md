# 变量管理器

入口：聊天输入区加号菜单 → 变量管理器。

## 功能来源

核对本机 SillyTavern 的 `public/scripts/variables.js`：原生全局变量位于 `extension_settings.variables.global`，聊天变量位于 `chat_metadata.variables`，提供 get/set 与变量列表命令。

核对已检出的酒馆助手代码 `src/function/variables.ts` 和变量管理器组件：可视化编辑、消息楼层及回复分支变量属于酒馆助手的扩展能力。MVU 使用消息变量中的 `stat_data` 存储角色状态。

本前端独立实现界面，直接读写这些兼容数据位置，不要求在旧酒馆页面打开插件面板。

## 当前支持

- 消息变量：选择楼层，修改当前回复分支的数据。默认选最近一条含有变量的可见消息。
- 聊天变量：只影响当前聊天的原生变量。
- 全局变量：影响所有聊天的原生变量。
- 搜索、每页 50 项、逐项修改及类型选择；对象/数组可用 JSON 编辑，支持添加或移除字段。
- 应用、搜索、切换页码不写入；点击保存后才持久化。未保存切换范围需确认，撤销修改恢复已保存值。
- MVU 状态通过当前角色的结构校验；保存后刷新角色脚本快照、聊天展示并使发送预加载失效。

保存时读取服务端当前值，检测其他页面修改、消息或回复分支变化。仅替换目标范围变量，保留正文、其他消息、备用回复和其他元数据。保存失败保留草稿；重新保存可处理服务端已成功但响应不确定的情况。保存期间阻止重复写入和聊天切换。

## 验收

使用独立两消息测试聊天验证消息数字从 7 改为 9，保存后重开仍为 9；备用回复分支仍为 99，正文不变。聊天范围的测试场景修改单独持久化，未覆盖消息变量。非法数字拒绝写入且输入保留；全局范围读取可用，未改动实际全局变量。

375px 手机视口无横向越界，逐项操作高 42px。测试聊天已删除，测试前的聊天位置已恢复。回归检查共 197 项，195 通过、2 项环境条件跳过、0 失败。

当前版本不提供预设、角色卡及脚本私有变量的独立范围；角色状态通过消息变量管理。
