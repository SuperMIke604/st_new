阅读约定（2026-10-26）：本文是应用 UI 约定的唯一来源。前部规范与明确的后续修订用于开发；历史截图、检查结果和“已发布”只描述对应时点，不证明当前工作区已验收。具体选择器和参数从 `public/app/controls.css`、`typography.css`、`style.css` 获取，不另建重复尺寸表。共享规则改变时更新本文；专项验收注明环境与日期。任务路由见 [AGENTS.md](../AGENTS.md)。

状态：规范及第 9.13 节起的增补随本次版本发布。后续补充条目优先于前文历史数值；各节旧发布状态仅保留当时记录。

字号层级已落地。第 8 节保留控件尺寸验收结果，第 9 节记录字号及后续 UI 修正；各次历史记录中的本地发布状态仅描述当时情况。

尺寸基准：按用户要求，统一为 **42px**。这里的 px 指 CSS 像素，包含边框；不根据截图缩放后的像素估算尺寸。

## 1. 统一尺寸

| 组件 | 统一尺寸 | 对齐方式 |
| --- | --- | --- |
| 单行输入框：文字、搜索、密码、数字、地址 | 高 42px | 文字垂直居中 |
| 选择框：原生、增强选择框、可搜索选择框的触发框 | 高 42px | 内容垂直居中，箭头位于右侧 |
| 文字按钮、图文按钮：主要、次要、危险操作 | 高 42px | 内容整体居中 |
| 独立图标按钮：读取模型、连接/预设工具、顶部导航等 | 42 × 42px | 图标水平、垂直居中 |
| 独立图标按钮的悬停、按下、选中底色 | 42 × 42px | 与按钮共用同一边界 |
| 输入框内的图标按钮：显示密钥等 | 点击区域 42 × 42px，状态底色 32 × 32px | 底色居中内缩 5px |
| 聊天输入区 | 单行状态最小高 42px | 多行时向上增长，旁边按钮保持 42px |
| 多行文本编辑器 | 最小高 42px，按用途增长 | 保留角色描述、正则代码、消息编辑等多行空间 |

单行控件在桌面和手机上都使用 42px。页面、工具栏、表单嵌套层级不产生新的高度规格。世界书紧凑条目、角色卡筛选栏和预设工具栏也纳入统一范围。

复选框、单选圆点、开关的图形本体按其形态绘制；独立操作行按 42px 对齐。卡片、展开条目、说明文字、代码区和多行编辑区按内容安排高度。

规范作用于应用自身界面。角色卡 HTML、小手机及第三方脚本内部界面继续遵循其自身配置；宿主提供的快捷回复按钮遵循本规范。

## 2. 字体、边框与间距

| 项目 | 基准 |
| --- | --- |
| 控件正文 | 桌面 14px，手机 16px；单行文字行高统一 22px |
| 标签文字 | 桌面 12px、手机 14px；与控件间距 8px |
| 输入框左右内边距 | 12px；有内嵌按钮的一侧预留按钮宽度 |
| 单行控件上下内边距 | 9px，配合 22px 行高和两侧各 1px 边框构成 42px |
| 边框 | 1px；普通、悬停、聚焦状态保持同一布局尺寸 |
| 圆角 | 输入框、选择框、按钮统一 10px |
| 按钮图标 | 20 × 20px，沿用现有线性图标风格 |
| 同行控件间距 | 8px |
| 相邻表单项间距 | 16px |
| 分组间距 | 24px |

保留现有纸色主题及主题色变量；本次规范不更换配色、字体资源和图标风格。其他主题也复用同一尺寸体系。

### 2.1 字号层级

手机端以视口宽度不超过 700px 为界。字号均为 CSS px；同一语义角色跨页面复用同一档位，不由所在页面单独决定。

| 文字角色 | 桌面字号 / 行高 | 手机字号 / 行高 | 字重 | 使用范围 |
| --- | --- | --- | --- | --- |
| 页面标题 | 22 / 30px | 20 / 28px | 600 | 连接与模型、预设、用户设定、世界书等面板主标题 |
| 分组标题 | 16 / 24px | 16 / 24px | 600 | 基础配置、提示词条目、核心操作等分区 |
| 卡片/列表条目标题 | 14 / 22px | 16 / 24px | 400 | 角色名称、预设条目名称、世界书条目名称 |
| 页面正文与说明段落 | 14 / 22px | 16 / 24px | 400 | 设置说明、空状态说明、普通内容 |
| 单行输入框与选择框 | 14 / 22px | 16 / 22px | 400 | 文本、搜索、密码、数字、模型与其他选择框 |
| 按钮与菜单选项 | 14 / 22px | 16 / 22px | 400 | 保存、取消、删除、快捷回复、下拉选项与导航文字 |
| 表单标签 | 12 / 18px | 14 / 20px | 400 | 连接名称、API 地址、模型等字段标题 |
| 辅助文字 | 12 / 18px | 12 / 18px | 400 | 次要提示、单位、时间、数量、楼层及状态说明 |
| 错误与通知正文 | 14 / 22px | 16 / 24px | 400 | 校验错误、成功通知、加载失败原因 |
| 只读代码、JSON、日志 | 13 / 20px | 14 / 22px | 400 | 使用等宽字体，保留缩进 |
| 代码及多行表单编辑 | 14 / 22px | 16 / 24px | 400 | 正则脚本、提示词、描述、消息源码编辑 |

字体沿用现有 `StorySans` 及系统中文字体回退链；代码使用等宽字体。使用 400、600 两档字重区分层级；主操作通过底色强调，危险操作通过语义色强调，按钮字号保持一致。

应用功能文字最低使用 12px。原有 8–11px 的标签、说明、状态和数量文字已统一到共享辅助字号，不通过缩小字号解决拥挤。

### 2.2 字号与 42px 控件的关系

- 输入框、选择框、按钮和单行菜单选项保持 42px；手机字号增加到 16px 时，行高仍为 22px。
- 有 1px 边框的单行输入/选择框按 `22px 行高 + 9px × 2 内边距 + 1px × 2 边框` 排布。无边框按钮通过居中布局维持同一文字基线。
- 控件的悬停、按下、选中、加载和禁用状态保持同一字号、行高和字重，不通过文字变大或加粗造成跳动。
- 长按钮名、长模型名优先通过省略、搜索、容器换行或布局调整处理；保留完整的可访问名称。说明文字和错误提示允许换行。
- 标题、说明段落和多行编辑区不受单行 22px 行高约束，按表中行高排布并允许内容增长。
- 浏览器缩放或系统字体放大后以可读性优先，提供换行和滚动，不用缩放文字抵消用户的显示设置。

### 2.3 聊天正文与角色内容

- 聊天正文默认 15px，继续沿用阅读设置中的 12–36px 字号范围、行距与段距。用户已保存的阅读偏好优先。
- 数据预览默认使用页面正文字号；已保存的 10–30px 独立阅读字号继续生效，工具栏保持界面控件字号。
- 聊天输入框属于表单控件，使用桌面 14px、手机 16px；消息源码编辑属于多行编辑，使用对应编辑字号。
- 角色卡 HTML、小手机和第三方脚本内部的字号继续按其自身配置展示；应用提供的面板标题、状态说明和快捷回复按钮遵守本规范。

### 2.4 字号落地与验收

已通过 `public/app/typography.css` 将页面标题、分组标题、正文、控件、标签、辅助文字和代码的字号/行高整理为共享变量，并清理原样式中分散的界面字号规则。

- 检查连接、预设、用户设定、世界书、角色卡、正则与脚本、数据管理、聊天工具及各编辑窗口，按“文字角色”比对字号。
- 桌面和 320 / 375 / 390 / 430px 窄屏分别检查；正文、标签、菜单和错误提示不能因页面不同出现额外字号档位。
- 字号调整后重新测量 42px 单行外框、图标居中、文字基线、长文本省略和窄屏溢出。
- 保留纯文字消息编辑按钮以及用户已有阅读设置，不通过整体缩小页面维持布局。

## 3. 图标与状态效果

以截图中的“读取模型列表”按钮为基准：

- 左侧模型框高 42px，右侧按钮为 42 × 42px，间距 8px，上下边界齐平。
- 图标为 20 × 20px，中心与按钮中心重合；不能继承文字按钮的左对齐规则。
- 底色直接绘制在按钮本身，不另加内外层偏移。默认、悬停、按下、聚焦、加载和禁用状态都不改变按钮的尺寸或位置。
- 读取模型属于即时操作。悬停/按下可以有底色，操作完成后回到默认状态；持续选中用于导航和开关类控件。
- 纯图标按钮保留明确的提示文字和可访问名称。加载指示占用原图标的 20px 区域。
- 密钥显示按钮靠右对齐，图标仍居中；其底色的上下边界与输入框一致。
- 保存、取消、删除等消息编辑按钮沿用用户指定的纯文字形式，不增加图标。

布局示意：`[ 模型选择框：高 42px ][间距 8px][ 图标按钮：42 × 42px ]`。

## 4. 选择框与输入框的行为

- 相同位置的输入框、选择框使用相同外框、圆角和文字基线；不因选择框位于复合行内而改变尺寸。
- 选择框内容过长时省略显示，箭头不被挤压。模型列表继续支持搜索和手动输入。
- 再次点击已展开的选择框收起列表；点击外部、按 Escape 或选择一项后收起。
- 预设选择框支持按名称搜索；无匹配结果时不创建新选项。角色卡排序框在手机上保留完整文字，工具栏空间不足时搜索框独占一行。
- 表单变窄时优先缩减输入/选择框宽度；图标按钮保持 42px，不挤压成窄条。
- 普通表单控件不得依靠 `min-height` 加不同的字体、行高和内边距间接决定高度。
- 手机端字号变化时保持 42px 外框，不再额外叠加高度覆盖规则。

### 9.17 轻提示 Toast（2026-10-26）

Toast 用于简短操作结果和状态反馈：不加遮罩、不阻断操作、不自动抢焦点。应用操作及角色脚本经宿主发出的提示共用同一组件；第三方隔离页面自行绘制的界面不在本规范范围内。

| 类型 | 场景 | 自动消失 | 示例 |
| --- | --- | --- | --- |
| success | 操作成功 | 3 秒 | 预设已保存 |
| info | 状态说明 | 3 秒 | 没有消息需要更新 |
| warning | 前置条件未满足 | 4 秒 | 请输入世界书名称 |
| error | 操作失败 | 5 秒 | 保存失败，请重试 |
| loading | 短暂异步操作 | 直到任务结束后调用方关闭，或用户主动关闭 | 正在保存… |

- 位置：页面顶部导航下方 16px、水平居中；面板打开时相对当前面板居中，位于标题区下方 16px。随窗口和可视视口变化重新定位，桌面左右至少留 16px，窄屏（不超过 700px）左右至少留 24px。
- 尺寸：短文案自适应；桌面最大宽度 480px，桌面面板内不超过可用宽度减 32px；窄屏不超过可用宽度减 48px。水平内边距 20px、垂直 14px，圆角 12px、1px 细描边，不绘制外阴影，避免堆叠容器滚动裁切产生矩形色块。保留纸色主题及其他主题的既有背景、文字与边框变量。
- 字号：复用通知正文字号，桌面 14/22px、手机 16/24px；所有类型均使用纯文字，不显示图标或加载环；通过明确文案说明结果和状态。单行整体居中，多行文字左对齐。
- 文案：优先 4–16 个汉字、最多两行的简短结果描述，通常不加句末标点。失败尽量说明下一步，不展示堆栈等实现信息。已有长错误不得直接截掉原因，允许自动换行、在最大 40dvh 内滚动；后续新增长篇诊断应放详情区。
- 关闭：点击任意位置立即关闭；焦点位于提示上时，Enter、空格、Escape 均可关闭。鼠标指针显示可点击状态，不另放关闭按钮。关闭 loading 仅隐藏提示，不取消业务任务；调用方完成后应通过 show 返回的 dismiss 句柄关闭该条，再显示结果。
- 计时：成功与信息提示均为 3 秒。悬停或键盘聚焦时暂停，二者均离开后按剩余时间继续。仅类型和原始文案逐字完全一致时合并，不去掉首尾空格、不忽略空格、换行或标点差异。重复触发只刷新对应条目的时长，不增加条目、不改变原排列位置，不重新播放入场动画或重复播报。
- 并发：多个不同提示按触发顺序从上向下排列，新提示追加在末尾，条目间距 8px；不覆盖、不按优先级丢弃。每条独立计时、独立暂停和关闭，移除后下方条目自然上移。提示区域超过可视视口剩余高度时可滚动，不越出屏幕。
- 动效：入场使用 160ms 淡入；点击关闭立即隐藏。减少动态效果开启时取消淡入。
- 无障碍：普通提示使用 status/polite，失败使用 alert/assertive，整条播报；保留键盘聚焦、关闭与暂停计时能力；聚焦时不绘制额外外框，仅保留容器 1px 细描边。提示不自动移动焦点。
- 面板层级：Toast 必须挂载于当前打开的对话框内部，再通过 popover 提升显示层级；仅放在对话框外部的顶层 popover 仍可能被模态交互隔离，造成可见但无法点击。

组件入口为 `public/app/toast.js`，应用 `notify(message, type)` 支持上述五种类型，同时兼容已有布尔失败参数。角色脚本 toastr 的 info/success/warning/error 保留对应语义，不将 warning 降级为成功。

使用边界：字段校验优先就地显示；需要确认或选择时使用对话框；长任务使用进度提示。当前数据库填表的“进度＋终止”保持独立组件，点击终止会取消任务，不套用 Toast 点击隐藏规则。当前未引入 Snackbar；未来如需“撤销、重试、查看”等操作按钮，使用单独规范，正文区域不按 Toast 点击关闭。
