# 正则与脚本

管理页保留全局、预设和角色卡正则，新增全局脚本、角色卡脚本。脚本支持查看、编辑、新建、导入、导出、启停与排序；原生文件夹结构及未知字段保留。角色脚本沿用 `data.extensions.tavern_helper.scripts`，全局脚本沿用 `extension_settings.tavern_helper.script.scripts`；保存范围开关时保留其他角色与原生设置。

进入聊天后自动运行当前角色已保存、已启用且通过兼容性检查的脚本。小手机等界面直接在聊天页面显示，沿用脚本自身的位置、大小、折叠和拖动配置；脚本注册的场景按钮放在输入框左侧新增的“快捷回复”菜单中。菜单支持再次点击、点击外部或 Escape 收起，执行按钮后自动收起。加号菜单的“脚本面板”用于查看状态和重新启动，管理页也保留入口。全局脚本仅保留管理，不执行或适配。

脚本仍使用不带 `allow-same-origin` 的独立 iframe，提供本地 jQuery、部分 lodash 方法、事件及变量接口；不把酒馆页面、连接配置、API 凭据交给脚本。页面 iframe 透明，仅保留脚本实际可见区域参与显示及点击；布局变化时更新裁剪区域，避免空白区域挡住聊天和输入框。快捷回复与对话工具菜单位于页面脚本上方。

## 当前接口范围

- 读取当前聊天的 MVU `variables[swipe_id].stat_data` 快照，以及聊天、角色变量。
- `Mvu.getMvuData`、`getVariables`、`getChatMessages`、`getLastMessageId`、`SillyTavern.chat/getContext` 和基本事件监听。
- `replaceVariables`、`updateVariablesWith`、`Mvu.replaceMvuData` 可保存当前聊天或消息的变量。主页面核对发起 iframe、聊天身份、消息索引、变量类型与大小；切换聊天、生成中或有未保存编辑时拒绝写入。不会通过这些接口改写消息正文。
- 提供脚本按钮注册与通知。`localStorage` 使用本次脚本面板内存，不承诺跨重启持久化。
- 上下文保留原楼层编号，只提供最近 40 楼的有限正文，以及有界变量快照。切换聊天或保存脚本后销毁旧环境；关闭面板后同一聊天内可再次打开。
- 识别原卡的 MagVarUpdate beta 单行导入，替换为内置 MVU 兼容，不下载或执行该远程模块。可从关联世界书的 `[InitVar]` 条目初始化变量，支持简单 YAML 映射及 JSON；不支持 YAML 锚点、标签或多行块。初始种子保存在当前聊天的自有元数据中。
- 完成模型回复后，在保存消息前处理 `<UpdateVariable><JSONPatch>`，支持 add、insert、replace、delta、remove、copy、move、test。所有操作验证成功后才提交变量；已有原生快照保持权威，不重复处理。重新生成使用新 swipe，旧候选保留。若输出正则移除了更新块，操作仍能从原始回复读取，并保留所需的分离操作记录，避免再次打开或编辑显示文字时丢失更新。
- 请求生成前也会准备已有变量。`get_message_variable::路径` 输出 JSON，`format_message_variable::路径` 输出兼容 YAML 文本，供提示词和正则使用；按选中 swipe 读取最新消息变量，无快照时使用初始化种子。递归排除 `$` 私有字段及原型字段。这是针对当前卡的接口子集，格式参考[酒馆助手变量文档](https://n0vi028.github.io/JS-Slash-Runner-Doc/guide/功能详情/变量/获取变量.html)，不承诺完整宏引擎或逐字一致的 YAML 格式。
- `getWorldbookNames/getWorldbook/replaceWorldbook` 对这张卡的场景配置提供受限兼容：仅可访问当前角色关联的世界书，只修改原有条目的启用状态，不新增、删除或覆写内容。写入前核对聊天身份、当前生成/编辑状态和条目 ID，写后重新读取核验。
- 脚本状态列表展示停用、未接入、已执行和失败；面板提供“重新启动”。iframe 没有可视内容时显示提示，而不是空白；未收到启动握手时显示失败说明。

## 尚未接入

完整的 MVU beta 外部模块、Zod schema 注册与转换、其他外部 ES 模块、IndexedDB 头像库、世界书内容编辑、创建或生成聊天消息、对酒馆原生 DOM 的访问，以及外部音频与网络资源。内置 MVU 兼容不等于完整 MVU beta 或 Zod 实现。识别到未接入的依赖时显示原因并跳过，不把“启用”当作“已兼容”。其他未知接口可能在运行时明确报错。
