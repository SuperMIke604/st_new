# 聊天记录管理

入口为输入框加号菜单中的“聊天记录管理”，原生实现，不依赖全局脚本。原“查找对话”入口已合并。只操作当前聊天，消息按最新在前展示，每页 50 条；支持搜索文字、全选结果、全不选、反选、两端点连选和楼层跳转。搜索结果摘要显示命中位置附近文字；可点击结果跳转，也可输入楼层编号后点击跳转或按 Enter。搜索及填写跳转楼层不产生待保存修改，有未保存消息修改或待插入内容时阻止跳转。

显示/隐藏、移动、删除和插入先修改面板草稿，点击“保存聊天记录”后写入；关闭未保存草稿需确认。移动保持选中消息的原顺序，目标为当前草稿中的楼层编号，填消息总数表示末尾。插入支持用户和角色消息，不请求模型。已有第三方脚本条目保持原样。

保留消息的变量、回复分支、未知字段与聊天头；来源发生变化的楼层之后按既有规则标记资料库快照 stale，不清空快照。保存前检查聊天身份、内存源数据和后端当前内容，写入后回读核验；保存期间阻止切换、生成及资料库写入。失败保留面板草稿，核验失败可能已经落盘，需重新读取确认。后端读后写不是跨页面原子事务。
