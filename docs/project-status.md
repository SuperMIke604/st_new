## 项目定位与当前能力

st_new 是运行在 SillyTavern `/app/` 的独立前端，使用原生 JavaScript ES modules，无独立构建或依赖安装步骤。官方后端承担认证、文件存储、模型转发和 tokenizer；本项目自行实现界面、生成上下文及兼容层，另提供可选更新插件。它不是完整官方前端或任意第三方扩展的替代实现。

| 领域 | 当前实现 | 详细依据 |
|---|---|---|
| 聊天与生成 | 单人聊天、流式/非流式回复、重生成与候选分支、提示词预览和精确预算；OpenAI 兼容连接独立保存 | [生成流程](generation-flow.md)、[持久化与接口](sillytavern-integration.md) |
| 资料管理 | 角色、预设、世界书、用户设定、正则的管理与保存；角色和世界书轻量目录可回退原生接口 | [架构地图](architecture.md)、[UI 规范](ui-design-guidelines.md) |
| 剧情资料库 | 表格快照、独立绑定的消息总结/数据库总结、可视化模板、当前聊天历史概览及删除、预览与草稿恢复 | [资料库契约](domains/lore-database.md) |
| 脚本与变量 | 隔离脚本宿主、统一助手 API 注册、远程模块兼容路径、全局/聊天/消息分支变量 | [脚本兼容](scripts-compatibility.md)、[助手宿主](remote-script-runtime.md)、[变量](variable-manager.md) |
| 消息呈现 | 虚拟列表、Markdown、隔离 HTML 卡片、阅读设置 | [HTML 兼容](html-card-compatibility.md) |
| 性能与诊断 | 资料与正则预热、有界缓存、世界书表单按展开创建、聊天条件 gzip 上传、分阶段加载日志及导出 | [性能约束](domains/performance.md) |
| 安装与更新 | 静态复制安装；可选插件提供目录/启动优化和确认式更新，校验失败或替换异常按实现回滚 | [安装入口](../README.md)、[开发与发布](development.md) |

## 待处理事项与建议顺序

以下是维护建议，不是已批准的实现计划；具体缺陷由对应契约维护，避免多份待办状态分叉。

1. 先处理已定位的语义边界：正则越界捕获组替换见 [架构关注点](architecture.md)；填表无变化响应与进度语义见 [资料库待办](domains/lore-database.md)。本次只静态复核相关代码，未修复或新增复现测试。
2. 核验真实部署与持久化：双总结、历史删除、模板保存的刷新回读及失败恢复；同时覆盖聊天切换、候选分支和未知字段保留。
3. 检查多用户与故障恢复边界：更新入口权限、跨页面整文件保存竞争、更新进程中断，见 [集成待处理边界](sillytavern-integration.md)。
4. 在固定部署版本和数据规模后测量性能与移动端行为；已有缓存和诊断能力不等于当前设备上的性能结论，见 [测量方法](domains/performance.md)。
