# HTML 消息美化兼容

本轮为“逐梦演艺圈”的基础美化、明星话题小组补齐消息上下文支持，保留角色卡原始正则及 HTML/CSS。

- `getCurrentMessageId()` 返回组件所属消息楼层。
- `getChatMessages(id)` 仅返回所属消息的原文；其他楼层返回空列表，不公开完整聊天历史。
- 支持两段原始美化使用的 `$(初始化函数)` 页面就绪写法；此接口不等于完整 jQuery。
- 基础美化通过组件序号区分同一楼的多个 `fate_ui`，无需访问父页面 DOM。
- 可选头像库以当前角色的本地记录提供按名称/别名查图及主角图查询；记录读取后刷新美化，缺少图片时保留组件自身的文字头像。

组件仍运行于不含 `allow-same-origin` 的 iframe；不开放网络请求或父页面访问权限。消息文本在嵌入时转义，避免内容提前关闭上下文脚本。

## 验收

使用卡片原始正则及原始替换代码走消息正则、Markdown、HTML 预览完整链路：微博、QQ、通告单分别渲染，未重复使用第一块数据。另在本地真实聊天验证 QQ 美化。

现有聊天不含 `star_zone`，因此向临时测试夹具加入两条虚构帖子，验证小组列表、分类筛选、详情回复及返回；桌面和 375px 视口均可展示。未改动角色卡、正则配置或原始聊天记录，未发送模型请求。私有夹具及角色卡代码不纳入仓库，验收完成后移除临时网页。
