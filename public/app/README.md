## 架构

这是独立静态前端，不是酒馆扩展，不加载 `/script.js`、原生编辑器、主题或第三方扩展。无需另外启动前端服务，也无需构建。后端仍是当前原生 SillyTavern 1.19.0，未修改服务器源码、路由或原生首页。

- `index.html` / `style.css`：电脑和手机界面。
- `main.js`：六项功能、应用状态、流式更新和保存。
- `api.js`：同源会话、CSRF、原生 API、串行设置保存及 SSE 解码。
- `engine.js`：独立提示词组装、基础宏、世界书激活、预设排序、上下文预算。
- `virtual-chat.js`：可变高度消息列表，可视区域＋缓冲区最多 40 个消息节点，保留完整聊天数据。
- `icons.js`：自行绘制的内联线性 SVG，无图标字体依赖。
- `vendor/`：随本地安装复制的 Showdown、DOMPurify 和许可证，仅用于 Markdown 与 HTML 清理。

没有 CDN、分析服务或后台自动调用模型。模型请求都由用户点击发送/重新生成触发，经酒馆后端转发。

## 功能

默认只显示聊天、输入框和顶部图标。API、预设、用户设定、世界书、角色卡直接放在顶部；其余工具按需打开，无品牌标题。

输入栏左侧“＋”集中提供查找对话、历史聊天、开启新聊天和更多工具。消息右上角“…”在消息内展开修改、复制、重新生成、删除；修改直接切换为原位文本框。重新生成适用于最后一条角色回复。用户设定支持新增独立身份，未上传头像时自动生成首字头像。

| 功能 | 首版实现 |
| --- | --- |
| API | OpenAI 官方 / 自定义 OpenAI 兼容接口、手动模型 ID、读取模型列表、后端保存密钥 |
| 预设 | 读取原生 OpenAI 预设、选择、导入、另存；逐条展开编辑名称、角色、内容、启停、顺序和深度；生成参数表单 |
| 聊天 | 列表、新建、继续、流式生成、停止、部分回复保存、编辑、删除、重新生成与回复分支切换 |
| 角色 | 文件管理式资料库、分类创建/重命名/删除、批量归类、桌面拖放、网格/列表、搜索排序、导入、编辑、创建 |
| 用户设定 | 头像、名称、描述、设定选择、绑定到聊天、关联世界书、上传头像 |
| 世界书 | 原生文件列表、前端独立启用列表、新建、导入、完整 JSON 编辑、生成时基础激活 |

预设通过表单逐条编辑，未展示的原生字段仍会保留。世界书条目暂时使用完整 JSON 编辑。角色分类存入 `independent_frontend.characterLibrary`，以头像文件名关联角色，不移动磁盘文件；删除分类只将其中角色移回未分类。

设置写入 `settings.json` 的 `independent_frontend` 命名空间；原生 personas 的编辑使用对应原生字段。`/api/settings/save` 是整文件覆盖接口，所以每次保存先读取最新设置，再仅合并需要改的字段。不要在原生页面与新页面同时编辑同一份设置；原生页面自身仍可能用旧快照覆盖文件。

角色保存使用原生 merge-attributes 接口，未展示的字段不主动删除。聊天保存保留 JSONL 元数据头和完整性标记，不使用 force 绕过完整性校验。失败时显示“未保存”，阻止切换和再次发送，可从工具中重试保存。

兼容连接密码按原生反向代理密码的方式保存在独立连接文件的各 profile.proxyPassword，刷新后可通过眼睛查看；同时提交 `/api/secrets/write`，生成请求沿用 secret ID。不写入 localStorage。留空表示保留后端当前密码。

## 生成兼容范围

支持原生单人聊天的常用路径，不是完整复制整个原生前端引擎。

- 预设 `prompt_order` 启停与顺序、标准 markers、自定义文本提示词、system/user/assistant 角色、深度注入。
- 角色 description/personality/scenario、示例对话、系统及历史后提示词覆盖、`{{original}}`。
- 基础宏：`char`、`user`、`description`、`personality`、`scenario`、`persona`、`charprompt`、`lastmessage`、`lastusermessage`、`lastcharmessage`、`trim`。
- 世界书：全局独立选择＋角色命名世界书＋用户关联世界书＋角色内嵌 character_book；关键词、常驻、次关键词逻辑、基础正则、概率、有限递归、描述前后和聊天深度插入。
- 世界书 token 百分比 / cap 和总体上下文预算，沿用后端 tokenizer 计数，超限裁剪最旧的聊天内容；不会截断磁盘聊天。
- 发送前可以在工具中预览提示词、tokens 和激活的世界书条目。自定义模型的 tokenizer 与真实模型是否一致仍需核对。

遇到未知宏、未知预设标记、部分高级世界书条件（sticky/cooldown/delay、向量检索、分组、角色条件过滤等）、不支持的插入位置、自定义请求体/请求头、聊天媒体附件时，会阻止发送并说明原因。文件里的字段仍保留。

尚未实现：群聊、文本补全后端、工具调用、多模态、扩展脚本执行、原生所有宏及复杂世界书规则。普通 Markdown 消息经过清理；HTML 消息在隔离 iframe 中渲染，支持内联 CSS、JavaScript、折叠、切换和输入点击交互。沙箱不开放同源权限、父页面访问、网络请求及表单提交。不要把此版当作任意原生预设、角色脚本的完全兼容替代品。

## 手机

- 390px 等窄屏布局，全屏设置/编辑/搜索面板，所有功能可通过点击操作，不依赖鼠标悬停。
- 16px 输入字体避免 iOS 输入自动放大；处理安全区域、visualViewport 高度与偏移、输入框自增长及代码横向滚动。
- 手机回车默认换行，点击按钮发送；桌面可用 Enter 发送、Shift+Enter 换行，输入法组词时不会误发送。
- 浏览器返回键优先关闭弹层；有未保存的编辑会确认。断流/停止保留已收到的回复，不自动重发导致重复请求。
- LAN HTTP 下的 UUID 和复制操作有兼容回退。

手机实际访问需使用 `http://电脑局域网IP:8000/app/`，并另行配置原生后端监听与访问控制。本次没有修改网络配置。窄屏浏览器模拟已验证；真实 iOS/Android 软键盘、系统杀后台、网络切换仍需实机测试。

预设内嵌 extensions.regex_scripts（兼容顶层 regex_scripts）自动载入，可在预设正则面板逐条编辑。支持输入/回复/世界书/思考内容、显示/提示词作用域、深度、编辑开关、捕获组、trimStrings 与基础宏替换；不加载正则扩展或执行 HTML 中的脚本，旧斜杠命令作用位置不执行。源文本正则在输入或回复保存时执行，显示及提示词正则分别处理派生内容，不覆盖磁盘原文。API 中选择流式/非流式；提示词后处理默认为 merge，调用原生后端合并相同角色连续消息，可改为不处理。

正则管理现为顶部独立入口，与预设/角色卡平级。全局规则存 settings.extension_settings.regex，预设规则存预设 extensions.regex_scripts，角色卡规则存角色 data.extensions.regex_scripts；执行顺序为全局→当前预设→当前角色卡，尊重各规则 disabled。管理时选择对象不会切换聊天。支持新建、导入、编辑、启停、复制、排序及删除。首次独立连接可从原生 reverse_proxy 继承反代地址，并将其对应凭据写入酒馆 CUSTOM 密钥槽，不回退到官方默认地址。

角色卡封面和聊天按钮进入该角色最后更新的一次聊天，启动时仍恢复之前打开的聊天。末条为用户消息且输入框为空时，发送会重试回复而不追加重复用户楼层。输入栏移除了模型/快捷键提示。API 顺序为地址、密钥、回复方式、后处理、模型；模型列表读取后更新原模型控件，可在下拉中搜索或手填模型 ID。刷新后的已保存密钥显示星号占位，不把占位符保存为真实密钥；眼睛通过原生 secrets/find 按权限读取，allowKeysExposure=false 时显示受限说明，不绕过或自动修改权限。

搜索模型的弹层使用固定搜索行和独立滚动列表，选中项滚入可视区时不会被搜索框遮挡。原生 oai_settings.proxy_password 与受 allowKeysExposure 限制的密钥库不同；对于已明确从原生反代迁移、地址和 secret ID 匹配的连接，使用已有代理密码，无需开启全局密钥库读取。新输入密码按连接保存以支持刷新后查看；历史纯密钥库条目仍遵守原生读取限制。

## API 多连接持久化

API 连接列表与 activeId 通过原生 files/upload 保存到当前用户的 `user/files/independent-frontend-connections.json`，不再依赖 settings.json 内的旧 connection 字段。因此原生页面用旧快照覆盖设置，不会丢掉连接列表。每个连接独立保存名称、地址、模型、密码、secret ID、流式与后处理。支持新建、复制、命名、选择、删除（至少保留一条）；保存后立即启用，切换和刷新保留当前选择。

连接密码随该用户的连接文件保存，眼睛直接切换显示，不请求 secrets/find 或修改 allowKeysExposure。旧版本只存密钥引用而无密码时，需要重新填写一次；已恢复的反代连接包含其备份密码。空密码连接使用明确的无密钥标识，不会误用另一连接的活跃密钥。45 项自动测试，加隔离浏览器验证：双连接切换、刷新、模拟原生 settings 覆盖、实际模拟请求的 URL/model/secret ID 匹配，以及 secrets/find 请求为零。

## 预设管理

## 内置数据库

顶部数据库图标打开数据表、模板、填表预设和更新设置。直接编辑单元格、表名和列名，支持增删表/行/列、分页、撤销、JSON 导入导出。模板属于当前填表预设，修改模板不会覆盖已有聊天快照；应用模板到当前聊天需单独确认和保存。

数据沿用原插件 chatSheets 和消息 TavernDB_ACU_Data 格式，按聊天保存；可直接读取旧聊天快照，并从更新设置导入旧插件配置或备份文件。填表预设支持逐条 system/user/assistant 编辑、新增、复制、删除和独立导入导出。不会迁移旧插件密钥或世界书同步设置，也不会写入世界书。

手动 AI 更新可选楼层范围、分批处理、随时停止；更新成功后一次写入，失败或停止保留原数据。自动更新默认关闭，开启后按回复次数触发，可跟随当前 API 或选用已有连接。开启自动更新会产生额外模型请求，旧聊天不会自动全量回填。数据库临时注入聊天请求并纳入上下文计数，不添加虚假聊天楼层；兼容 tableData 和 sheet_* 宏。

消息编辑、删除、切换回复和重新生成会使相关派生快照失效。历史快照可恢复为草稿；同楼层被覆盖的旧版本最多保留 8 份且总量限制为 2 MB。每个数据库限制 3 MB、100 张表、每表 5000 行和 64 列。
